# Sistema actual (referencia)

Este directorio guarda las **instrucciones del sistema actual** —la metodología
con que Roberto lleva su diario de sueños hoy, como proyecto de Claude— para que
la app se construya fiel a ellas.

Es **metodología, no corpus**: son las reglas del sistema, no el contenido de los
sueños de Roberto. Por eso se versiona aquí. El corpus (bitácoras, entidades,
taller) nunca entra al repositorio (ver `../../README.md`, sección Privacidad).

- `instrucciones-v7.2.md` — borrador consolidado del 13 oct 2026, entregado por
  Roberto. Gobierna qué debe replicar la app. Donde la app mejora o reemplaza
  una regla (por ejemplo, todo el andamiaje de "dos hilos" y "handoff" que la
  base de datos vuelve innecesario), queda explicado en
  `../plan-implementacion.md`, sección 17.
